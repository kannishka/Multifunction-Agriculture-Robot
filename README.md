# Multifunction-Agriculture-Robot
🌱 Arduino-Based Smart Grass Cutting Robot

This project is an Arduino Uno–based autonomous grass-cutting robot designed to move around a lawn while detecting obstacles and cutting grass using a dedicated DC motor. A 12V battery powers the drive motors and grass-cutter motor, while an L298N motor driver, relay module, sensors, and optional Bluetooth control work together to manage movement, speed, and cutting operations.

Key Features:
🤖 Arduino Uno control
🔋 12V battery-powered system
🚗 Four DC motors for movement
🌱 Dedicated DC motor for grass cutting
⚡ L298N motor driver
🎛️ Motor speed control using enable pins 
🔌 Relay-based grass-cutter motor control
